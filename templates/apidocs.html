POST /api/auth/register Registrasi Akun Pengguna Baru
🔓 Public

Mendaftarkan user baru ke sistem dan mengembalikan JWT Access Token secara langsung.

Request Body (JSON)
{
  "name": "Budi Santoso",
  "email": "budi@example.com",
  "password": "password123"
}
Response Sample 201 CREATED 
{
  "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6...",
  "user": {
    "id": 1,
    "name": "Budi Santoso",
    "email": "budi@example.com"
  }
}
curl -X POST https://arya124-wayanusa-v2.hf.space/api/auth/register -H "Content-Type: application/json" -d '{"name":"Budi","email":"budi@mail.com","password":"pass"}'

PUT /api/auth/profile Perbarui Profil & Password
Bearer Token

Memperbarui nama, email, password, dan foto profil. Format request menggunakan multipart/form-data.

Field FormTipeWajibDeskripsi

namestringTidakNama baru pengguna
passwordstringTidakPassword baru yang diinginkan
profile_picfileTidakFile gambar (JPG, PNG)
POST /api/predict-wayang Klasifikasi Tokoh Wayang dari Foto (Scan AI)
🔓 Public

Mengirim citra wayang via form-data untuk diklasifikasi oleh model Deep Learning (CNN/MobileNet). Mengembalikan nama tokoh, tingkat akurasi (confidence), dan deskripsi filosofis karakter.

ParameterTipeFormatDeskripsi
imagefilemultipart/form-dataFile foto wayang (JPG/PNG maks 10MB)
Response Sample (Berhasil)200 OK
{
  "status": "success",
  "prediction": "Gatotkaca",
  "confidence": 98.45,
  "confidence_text": "98.45%",
  "deskripsi": "Gatotkaca adalah ksatria perkasa dari Pringgandani, putra Werkudara yang berotot kawat bertulang besi.",
  "gambar_referensi": "static/images/wayang/gatotkaca.png"
}
